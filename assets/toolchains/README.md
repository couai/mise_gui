# 官方工具标识

素材直接取自项目官网或官方组织的源码仓库，保留原始文件、颜色和比例，未重绘。下载地址和 SHA-256 见 [sources.json](sources.json)。离线打包使用，不在应用运行时访问图标网站。

| 工具 | 使用的官方素材 | 来源及使用说明 |
|---|---|---|
| Java | OpenJDK Duke / Hips | [OpenJDK Duke 项目](https://openjdk.org/projects/duke/)、[官方素材仓库](https://github.com/openjdk/duke) |
| Node.js | Hex Logo | [Node.js Branding](https://nodejs.org/en/about/branding)、[OpenJS 商标政策](https://trademark-policy.openjsf.org/) |
| Python | Two Snakes 标识 | [PSF 官方 Logo 页](https://www.python.org/community/logos/)、[商标政策](https://www.python.org/psf/trademarks/) |
| Go | 官方 Gopher，Renee French 创作 | [Go 品牌说明](https://go.dev/brand)，Gopher 为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Rust | 官方齿轮标识，含原版深色背景变体 | [rust-lang/rust-artwork](https://github.com/rust-lang/rust-artwork/tree/master/logo)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；原始作者及贡献者见上游 |
| Flutter | 官方 Flutter Logomark | [Flutter Brand](https://flutter.dev/brand)、[商标指南](https://docs.flutter.dev/brand) |
| Dart | 官方 Dart 标识 | [Dart 官方网站源码](https://github.com/dart-lang/site-www)、[品牌指南](https://dart.dev/brand) |

上述图形的版权、商标及许可由各权利人保留，不因本仓库采用 MIT 协议而改变。它们仅用于识别正在管理的工具，不代表本应用得到对应项目的背书。Java 使用 Duke 形象，Go 使用官方 Gopher。
