# 代码与 Issues 检查记录

检查日期：2026-10-18。范围为本机 macOS ARM64 的导航、分类安装、版本查询和配置编辑，以及上游开放 Issues。个人 fork 未启用 Issues，本轮没有修改上游 Issue 状态或发送评论。

## 导航与安装入口

菜单顺序调整为：总览 → 工具链 → 工具 → 项目 → 配置。路由分支与导航枚举保持相同顺序，总览仍是默认启动页。

“工具 → 安装工具”在显示确认弹窗前，调用 ClassifiedToolchainService.prepare，把原始 `mise install` 转换为 `mise install-into`、`mise link` 和 `mise reshim`；执行层再次验证同一计划。分类规则来自 ToolchainLayout，与“工具链”页面一致。

相对于 `$HOME/Developer/toolchains`，新增 Java、Node.js、Python、Go、Flutter 分别安装到 `jdk/versions/`、`nodejs/versions/`、`python/versions/`、`go/versions/`、`flutter/versions/` 下的精确版本目录。Rust 通过 rustup 安装到现有 RUSTUP_HOME，使用现有 CARGO_HOME 代理并注册到 mise。现有 SDK 的路径保持原状。

安装不会自动切换全局默认。修正了弹窗中与此相反的旧文案，以及误导用户填写 latest、主版本别名或未支持工具的提示。当前分类安装支持上述六类运行时，其他工具会明确拒绝。

`tools_install_flow_test.dart` 通过真实页面按钮进入预览和执行，在隔离目录使用离线安装器替身生成文件，验证预览与执行目标相同、先确认后执行、没有默认 mise 安装目录落盘，也没有写入全局版本配置。未为测试额外下载 SDK。

## 已复现并修复的问题

| 问题 | 原因及处理 | 回归验证 |
|---|---|---|
| [#21 Flutter 最新版识别错误](https://github.com/likaia/mise_gui/issues/21) | 比较时字母前缀可能排在数字前；仅优先选带 stable 后缀的条目，又会排除新版无后缀发布。比较版本数字时去除前缀，统一判断稳定版本并排除预发布。 | 旧 v1 标签与新版混合、不同 stable 后缀、Java 发行商前缀、预发布排序 |
| [#19 已是最新版时显示较旧版本](https://github.com/likaia/mise_gui/issues/19) | 最新版取自排除当前版本后的可安装候选列表。现在从完整稳定目录选最新版，安装候选列表单独保留。 | 当前版本与远端最新相同，仍显示当前版本且不提供升级 |
| [#18 远端请求阻塞本机版本](https://github.com/likaia/mise_gui/issues/18) | 展开工具后等待远端数据，未返回时只显示加载界面。现在立即展示已安装版本，远端查询与错误提示单独呈现。 | 使用一直未完成的远端 Future，确认本机版本已经可见 |
| [#22 XDG 路径兼容](https://github.com/likaia/mise_gui/issues/22) | 补齐 XDG_CONFIG_HOME、XDG_DATA_HOME、XDG_CACHE_HOME、XDG_STATE_HOME 回退；明确的 MISE_* 变量优先。代理读取同一个有效配置文件。Windows shims 路径也按 MISE_DATA_DIR / XDG_DATA_HOME 解析。 | XDG 路径、显式代理配置路径、Windows 路径解析单元测试 |
| 更新状态无法清空 | ToolRecord.copyWith 把显式 null 当成“不修改”，会保留过期的升级提示。区分省略参数与显式清空。 | 更新状态保留与清空测试 |
| 安装建议退回测试版或 JRE | 稳定 SDK 筛选为空时回退到原始列表，重新建议被排除的版本。现在返回空建议，允许手动填写精确版本。 | 只有 Flutter beta 或 Java JRE 的目录 |
| 配置编辑覆盖外部修改 | 编辑页持有旧快照，保存时直接覆盖文件。保存前检查文件是否被创建、删除或修改，冲突时提示刷新。 | 加载后由外部修改文件，再保存被拒绝且外部内容保留 |

上游 #17 为模糊搜索功能请求、#1 为用户交流群，不作为本轮 bug 修改。已关闭问题通过现有测试覆盖相关行为；锁文件仍由 mise 管理，避免误删其他终端的有效锁。
