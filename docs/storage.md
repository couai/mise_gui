# 目录与缓存

入口为侧栏“目录与缓存”（`/storage`）；工具档案中的“查看目录占用与链接”按归属工具筛选。

## 数据范围

`DirectoryStorageService.scan()` 复用本地工具清单，补充分类根目录的一级条目及已约定的兼容路径。相同登记路径合并所有归属；自定义导入工具保留归属，未登记的一级条目标为“未关联分类”。项目代码、node_modules、Rust target 不在扫描范围内。

只读取文件系统元数据和软链接目标，不读取业务配置、凭据或日志内容，不运行导入的程序。扫描不移动目录、修复链接或清理缓存。

- 界面、CLI 验证均调用同一个扫描模块；列表支持名称/路径搜索、目录类型、工具归属、待检查、软链接及未找到项筛选。顶部汇总始终覆盖全部登记路径。
- 元数据检查最多 16 项并发，单项 5 秒；磁盘测量最多 2 项并发，单项 30 秒，逐批返回进度与结果。
- 首次进入或手动刷新才扫描；切换页面保留结果，仪表盘的定时刷新不触发目录测量。停止扫描会终止当前测量进程、跳过排队任务并保留已测结果。刷新创建新的取消会话，应用关闭时取消当前会话。
- `directoryStorageProvider` 不订阅工具清单的周期性变化；“重新扫描目录”会更新工具清单后测量。时间显示的是该次扫描起点，文件在扫描期间可以变化。

## 空间口径

`PosixDirectoryUsageReader` 使用系统 `du -sk -P -x <实际路径>`，按文件系统报告的已分配空间统计，单位以 KiB/MiB/GiB 展示。稀疏文件不按逻辑文件长度累计。命令使用参数数组和绝对路径，输出有上限；不跟随目录内部软链接，不跨文件系统递归。

- 各行展示本路径的测量结果。同一实际目标只测量一次；汇总排除相同目标及已被祖先覆盖的子路径。详情列出覆盖根目录，避免将 SDK、缓存子目录及兼容软链接重复累加。
- 缓存汇总只覆盖已声明为缓存的路径，是总占用的一部分；混合配置与依赖的 `.m2`、Gradle 用户目录不整体当作缓存。分类标签不等于清理许可。
- APFS 克隆及不同根目录之间的硬链接可能共享磁盘块；数值不是唯一物理块统计，也不代表删除后可释放空间。
- 无权限、命令失败或超时不当作成功的 0。部分可读结果用下限表示；未测或取消项没有数值。不完整汇总标记 `≥`。
- `/`、整个用户目录等过宽路径只检查元数据。`/Volumes`、`/Network`、Apple 模拟器运行时挂载目录不递归测量，并明确注明未计入。

## 链接和路径规范

逐段检查符号链接，解析相对目标和父目录链接，展示最终实际路径及链接链路；区分未找到项、失效目标、循环和无法检查。合法链接下尚未创建的子路径不误报断链。

规范判断依据实际目标，运行时分类沿用 `ToolchainLayout.categories`，其他分类与兼容目标由扫描模块集中声明。共享的 mise 配置、npm 随 Node.js、pip 随 Python、Flutter 配套 Dart 等路径允许关联分类。

- 兼容路径需指向约定的实际目标；错误目标标记“兼容路径指向异常”。默认原路径若仍为实体目录，也列为待检查。
- GUI 应用、系统程序、Homebrew 程序分别保留 `/Applications`、系统程序目录和 `/opt/homebrew`；Apple 管理的模拟器数据、macOS 原生偏好设置、Git/GitHub 标准账号配置保留原生位置，并展示原因。
- IDE 等配置、缓存与日志仍在分类目录之外时标记“分类目录外”。这表示布局待核对，不表示自动判定工具安装损坏，也不在本步骤迁移它们。
- 位于集中根目录但归属分类不匹配的路径另行标注。新分类与例外需有明确依据，避免把所有原生缓存都加入豁免。

快速打开复用 `LocalToolOpener`，点击时再次确认路径；文件在 Finder 定位，目录正常打开，应用包在目录页打开其父目录。失效链接可打开父目录，失效目标自身不提供打开按钮。支持复制路径和跳转工具档案。

## 验证

```sh
mise exec -- flutter analyze
mise exec -- flutter test
mise exec -- dart run tool/check_storage.dart
bash scripts/build_local_macos.sh
```

`test/directory_storage_test.dart` 覆盖空间去重、归属、规范、相对/父目录/失效/循环链接、稀疏文件的实际占用、原生命令超时及取消；`test/storage_page_test.dart` 验证筛选、快速打开失败、工具跳转、停止/刷新、导航缓存和窄窗口。测试只在隔离目录修改权限和创建数据。

设置 `DEVWORKBENCH_RENDER_STORAGE=1` 并沿用设计预览的字体环境变量，运行页面测试可只读扫描本机后生成 `docs/design/storage.png`。macOS 是本阶段验证平台。
