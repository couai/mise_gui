# 任务中心与管理器设置

任务中心跟踪 mise 分类安装／切换、mise 配置保存、目录扫描、管理器配置保存与检查，以及工具维护的原生安装、更新、卸载和定向缓存清理。自动总览刷新、普通版本读取与快速打开不生成任务，避免重复记录。

## 执行与验证

- `TaskCenter` 持有任务，页面仅观察。切换页面或关闭进度弹窗后工作继续；任务随应用进程执行，重启后未收到终态的旧任务标为“已中断”，由用户核对实际状态，不自动重试。
- 展示每一步的待执行、执行中、成功、失败或跳过状态，以及命令退出码、时间、输出和最终验证。进度是完成步骤数，单个下载命令不虚构下载百分比。目录任务另显示已测目标数量，可在任务中心或目录页停止扫描。
- 写操作通过 startMutation 共用任务锁，覆盖 mise、配置、Homebrew、Android 和缓存维护；其他任务运行时界面禁用管理器设置保存，保持已有操作的配置上下文。
- 命令退出成功后重新查询 mise 注册信息，检查 SDK 分类目录和必要程序；切换还检查全局／指定项目作用域中的实际激活版本。验证失败显示为失败，即使命令 exit 为 0。配置保存则回读比较内容，保留已有外部修改冲突检查。
- 目录扫描有待核对路径或不完整测量时标为“需检查”。停止扫描保留部分结果；命令失败、超时和异常均保留已完成步骤与错误输出，后续步骤跳过。

## 管理器配置

配置文件：`<toolchains>/mise-gui/config/managers.json`。仅影响 DevWorkbench 的后续操作；不改终端环境入口、系统 `xcode-select`、现有 SDK、缓存目录或应用安装位置。路径变更不迁移数据，工具识别和目录扫描会重新读取新配置。

| 管理器 / 范围 | 可配置项 | 应用位置 |
|---|---|---|
| mise | 程序绝对路径（空值使用登录 Shell 查找）、强制离线、操作超时 | 查询、分类安装、注册、版本切换；关闭强制离线后沿用 mise 原网络配置 |
| Homebrew | brew 程序、安装前缀 | 工具识别、版本检查、目录归属；本地检查固定关闭自动更新与分析 |
| Android SDK | SDK 目录 | 平台、NDK、CMake、ADB 识别和扫描；命令环境的 ANDROID_HOME / ANDROID_SDK_ROOT |
| Xcode | Developer 目录 | 工具档案、xcodebuild 检查和命令环境的 DEVELOPER_DIR |
| 执行与扫描 | 本地检查超时、单目录测量超时 | 工具版本探测、管理器检查和 du 测量 |

管理器检查按固定参数调用 `mise --version`、`brew --version`、SDK 内 `cmdline-tools/latest/bin/sdkmanager --version`、Developer 目录内 `usr/bin/xcodebuild -version`。任一失败仍继续检查其余管理器。设置不拼接任意 Shell 参数；路径允许空格，保存要求目标存在、程序可执行，超时选项有范围限制。

Rust 仍由 mise 调用原有 rustup，Dart 仍随 Flutter；npm、pnpm、pip 等沿用现有运行时和分类配置。Homebrew 与 Android 的原生维护和定向缓存清理见 [工具维护约定](maintenance.md)；Xcode 保留原应用与 App Store 维护，本页负责路径配置与版本检查。

## 记录与维护

任务记录：`<toolchains>/mise-gui/state/tasks.json`，保留最近 40 项完成记录及当前执行任务；每项输出保留末尾约 32K 字符。输出去除终端控制序列并遮盖常见凭据格式；配置保存只记录路径和结果，不记录 TOML 内容或环境变量集合。

配置和任务文件采用临时文件后原子替换，POSIX 文件权限 600。损坏文件保留，页面提示保存／读取失败；正常任务仍可在当前会话查看。任务写盘串行、实时输出合并写入，避免频繁磁盘刷新。设置写入失败时保留当前生效配置。

普通测试使用隔离或内存存储，不读写用户的工作台配置。`DEVWORKBENCH_LIVE_MANAGERS=1 flutter test test/manager_live_test.dart` 是显式本机验收：仅保存工作台的当前管理器设置和真实版本检查记录，不变更 SDK 或全局版本。
