# DevWorkbench 1.7.1

版本：1.7.1（build 19）。本版降低工具扫描和列表显示的资源占用。

## 改动

- 总览自动刷新从每分钟改为每 5 分钟；手动刷新保留，页面隐藏或应用不活跃时暂停自动刷新。
- 工具探测改为串行，减少大型 CLI 同时启动造成的内存峰值。
- 工具列表按可见范围构建，减少刷新和选择工具时的对象创建。

本机各一次 8 秒启动采样中，应用与扫描子进程的 RSS 峰值从 492.8 MiB 降至 388.9 MiB，约下降 21%。这不是所有电脑的固定内存上限，空闲内存基本持平。

## macOS 安装

- 下载 `DevWorkbench-1.7.1-macOS-universal.dmg`，打开后将 `DevWorkbench.app` 拖入 `Applications`。
- 安装包同时包含 arm64 和 x86_64，应用声明最低 macOS 12.0；本次运行验收为 macOS 26.7.1 / Apple Silicon，未在 Intel 实机验收。
- 更新保留原有配置、项目和工具分类目录。安装包只包含应用、安装说明和 MIT 许可证。
- 校验值见附件 `SHA256SUMS.txt`；[GitHub Release](https://github.com/couai/mise_gui/releases/tag/v1.7.1)。

沿用 ad-hoc 本地签名，未做 Apple Developer ID 签名或 Apple 公证。首次打开可能需要在 macOS「隐私与安全性」中确认来源。

## 验证

静态分析及 macOS Release 构建通过；249 项测试通过、2 项本机测试按原设置跳过。新增回归覆盖探测并发、5 分钟刷新、手动刷新及后台暂停；保留工具选择和页面切换测试。发布安装包另行核对 DMG 完整性、包内版本、双架构、签名和 SHA-256。
