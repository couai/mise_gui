# DevWorkbench 1.7.0

本地开发工具工作台，保留 mise 的分类目录和版本管理。

## 本版功能

- 统一总览、工具档案、分类识别、手动导入和快速打开。
- 唯一的 mise 版本管理入口；已安装 SDK 的全局／项目选择与分类安装分别处理，Dart 跟随 Flutter。
- 目录与缓存展示真实占用、归属、软链接状态和异常路径。
- 任务中心记录步骤、输出与验证结果；管理器设置支持 mise、Homebrew、Android SDK 和 Xcode。
- Homebrew／Android 单项维护，以及 npm、pip、uv、Go 编译缓存的定向清理。
- 项目诊断核对实际 npm/pnpm、Python 虚拟环境及 pip 安装元数据、Maven/Gradle 多模块、编译级别与工具链；保留扫描完整性与不确定项。
- 修复跨语言版本比较、TOML 声明解析、探测失败状态及本地打包输出目录；npm 声明同步至 11.19.0。

## macOS 下载与安装

- 版本：1.7.0（build 18）。
- 安装包：`DevWorkbench-1.7.0-macOS-universal.dmg`，包含 arm64 与 x86_64。实际运行验收平台为 macOS 26.7.1 / Apple Silicon；应用声明最低 macOS 12.0，其他系统及 Intel 实机未作运行验收。
- 打开 DMG，将 `DevWorkbench.app` 拖入 `Applications`。运行时工具继续沿用已有分类目录，程序首次打开不会自动迁移 SDK 或更改全局默认版本。
- 发布包仅包含应用、安装说明和 MIT 许可证，不携带本机配置、缓存、SSH 密钥或数据库连接。
- SHA-256 校验值见同一 Release 的 `SHA256SUMS.txt`。发布页：[DevWorkbench v1.7.0](https://github.com/couai/mise_gui/releases/tag/v1.7.0)。

此包采用 ad-hoc 本地签名，**没有 Apple Developer ID 签名或 Apple 公证**；GitHub 的正式 Release 标记不等于 Apple 公证。首次打开可能被 Gatekeeper 阻止，可参考 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac) 自行确认来源后操作。
